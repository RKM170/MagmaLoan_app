# Magma Loan Finance Website

A responsive and modern loan finance website built for a real local business using HTML, Tailwind CSS and JavaScript.

## Features

* Responsive design
* WhatsApp lead generation
* Loan application automation
* Owner branding section
* Animated finance offer bars
* Mobile-friendly UI
* Interactive loan cards
* Contact & inquiry section

## Real-World Problem Solved

This website helps customers directly connect with the loan provider through WhatsApp instead of traditional offline communication.

Customers can:

* Apply for loans instantly
* Send loan details directly
* Contact through WhatsApp
* Explore different loan services easily

## Business Impact

The website improves:

* Customer trust
* Online visibility
* Lead generation
* Faster communication
* Professional business presence

## Technologies Used

* HTML5
* Tailwind CSS
* JavaScript

Hosted using Netlify / Vercel
